# Screenshots and Execution Evidence

This directory contains execution evidence for the **Student Performance Analytics System**.

## Contents:
- **`terminal_output.png`**: High-resolution terminal capture showing the complete execution of `python main.py` including dataset overview, student table, class performance, subject analytics, top performers, attendance, department metrics, and insights.
- **`terminal_output.txt`**: Complete, unedited raw console log from running `python main.py`.

## Manual Screenshot Guide (Optional):
If you wish to capture custom screenshots from your own local terminal window:
1. Open PowerShell or Command Prompt.
2. Run `python main.py`.
3. Press `Win + Shift + S` to open the Windows Snipping Tool.
4. Capture the desired section and save it in this `screenshots/` directory.
